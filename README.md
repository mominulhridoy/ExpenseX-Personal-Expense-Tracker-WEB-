# ExpenseX-Personal-Expense-Tracker-WEB-


💰 Expense Tracker - Web Engineering Project
This project is a Web-based Expense Tracker built with HTML, CSS, PHP, and MySQL.


## 📁 Project Structure

📂 config/: Contains the database connection and environment settings.

📂 controllers/: The "Engine" of the site containing PHP logic for adding, deleting, and editing data.

📂 models/: Contains the database interaction logic and schema definitions.

📂 views/: The actual screens the user sees (Login, Dashboard, Signup).

📂 auth/: Dedicated folder for login, registration, and session security.

📂 core/: Core system files like CSRF protection and Authentication helpers.
